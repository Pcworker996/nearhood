## Storage, API and UI responsibilities

Keep original Reports and derived extraction separate. Extend private Report processing with compatible stage checkpoints/versions and a full assessed-pool/evidence snapshot, while keeping displayed candidate IDs and attributed decisions distinct. Preserve originals, existing memberships and account history during migration; use new versioned migrations, not edits to applied migrations or automatic live-provider backfills. Storage layout, exact schema fields and numerical budgets are preflight deliverables, not an invitation to infer product behavior.

Retain immutable save at `POST /api/reports`, owner-only recovery at `GET /api/reports/:id`, stage advancement through `POST /api/reports/:id/process`, and confirmation at `POST /api/reports/:id/match`. Recovery returns understandable phase/reason/next action and cannot expose private auth/provider diagnostics. The client advances the next saved stage with an authorized POST; GET has no processing side effect. A model error leaves the Report and compatible checkpoint saved for retry.

The public UI distinguishes saved/pending/unassigned Reports from incorporated evidence. Do not invent an account or imply a successful update while processing. Candidate clarification already uses choices and explicit uncertainty; interactive multiple-occurrence answers are outside the hackathon. Initial account publication preserves claim-to-Observation-to-original-Report links. #5 owns the later evidence reconciliation and account-change demonstration; any synthesis call has its own validated budget.

## Deferred and unchanged requirements

No embeddings, physical-object registry, autonomous tool loop, automatic merging or automatic distribution across Happenings. Use the same qualified Nemotron model for both stages initially; separately optimizing extraction is later work. The narrowed multiple-occurrence behavior is an accepted scope decision, not a claim that the failed live extraction case has been fixed. This ticket stays open until the revised criteria and live/hosted checks pass.
