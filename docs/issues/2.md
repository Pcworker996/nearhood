## Milestone exits

1. **#4 implementation preflight:** freeze versioned extraction/matching schemas and recovery contracts; document input/evidence/stage limits and reviewed evaluation gates. Exact numeric budgets require measurement, not assumptions.
2. **#4 extraction checkpoint:** preserve immutable saving/auth/idempotency; run dedicated extraction; validate/save JSON separately; survive reload and matching failure without repeating compatible extraction. Handle multiple separate occurrences with saved/unassigned explanation.
3. **#4 larger-pool matching:** deterministic nearby retrieval; separate matching call with JSON plus original evidence; semantic comparison before top-five display; contributor confirmation and attributable decisions; no forced separation for conflicting evidence; no unsupported new occurrence on uncertainty, failure, insufficient coverage or rejection of only displayed candidates. Each provider stage is resumable under its own request/lease; verify total input and stage budgets.
4. **#4 qualification:** compare combined-call and two-stage strategies on reviewed scenarios; measure candidate recall, wrong merges, misses, uncertainty, latency and usage. Verify live Google/Nebius, hosted migrations and the actual deployment database target. Resolve/reproduce overlapping-marker failures in an isolated test database before claiming a green suite. Schema/model validity and controlled fixtures alone do not prove semantic quality.
5. **#5 hosted hackathon milestone:** two distinct contributors, one bridge Happening, confirmed later-report membership, scoped partial improvement, preserved originals, supported claims, prior/current account and uncertainty through deployed real persistence and runtime model calls. Reject overbroad full reopening, preserve contradictory evidence and late observation chronology, and verify retry/stale-result safety.
